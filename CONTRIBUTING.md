# Contributing to NGHT-RDR's Portfolio
Thanks for taking a look! It means a lot! :D

Because this is my portfolio, I'm only open to small contributions. These are:
- Issue submissions (Bug reports, feature requests, etc...)
- Hotfixes

## Submitting an issue
If you notice a bug or you have an idea for a new feature, the best way to bring it forward is by submitting an issue [here](https://GitHub.com/SweetBoy13735/SweetBoy13735.GitHub.IO/issues) (Please ensure a similar one doesn't exist first).

### If you've spotted a bug:
1. Label the issue as a bug and briefly elaborate in the title.
2. Dive into further detail with a full description. Please include relevant media and/or console outputs if possible. If you can consistently replicate the bug, document the steps you took.

### If you want to request a feature:
1. Label the issue as an enhancement and briefly elaborate in the title.
2. Dive into further detail with a full description. Feel free to include relevant media.

## Writing a hotfix
If you'd like to take on a critical bug, here's what you'll need to do:
1. Fork the repository and commit your code to a hotfix branch off `Main`.
2. When you're done, create a pull request targeting my `Main` branch. Title the pull request as `Hotfix vX`, where `X` is the current version incremented by one patch (E.g. `v1.0.0` -> `v1.0.1`).
3. Add me (`SweetBoy13735`) as a reviewer of the changes and link any relating [issues](https://GitHub.com/SweetBoy13735/SweetBoy13735.GitHub.IO/issues) in your description.
4. Once I'm happy, I'll approve the merge!
